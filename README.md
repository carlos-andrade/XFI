## Regra operacional

Todo o material substancial produzido neste projeto deve ser guardado neste repositório quando o formato e os meios disponíveis o permitirem. Não basta mostrar o resultado na conversa: é necessário confirmar a gravação e registar o commit.

Antes de alterar qualquer ficheiro, leia o conteúdo atual e preserve o histórico. Não declare que algo foi executado, testado, validado ou publicado sem evidência verificável. Nunca guarde segredos, tokens, credenciais ou chaves privadas.

## Fluxo de trabalho

1. Inspecionar a estrutura e os ficheiros relevantes.
2. Definir o escopo e localizar os caminhos corretos.
3. Produzir ou atualizar os artefactos.
4. Executar verificações apropriadas e indicar limitações.
5. Rever as alterações e gravar no GitHub.
6. Confirmar o commit e comunicar caminhos, validações e pendências.

Consulte a governança do projeto para as regras completas.
